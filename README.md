# Actividad 2: Gestión de Lista de Compras (Estructuras de Datos)

## Descripción
Sistema modular para la gestión de lista de compras en JavaScript utilizando arreglos. Implementa validación rigurosa contra duplicados, insensibilidad a mayúsculas/minúsculas mediante normalización, eliminación con reindexación y visualización formateada.
